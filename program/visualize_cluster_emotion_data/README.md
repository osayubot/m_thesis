# クラスタ単位の感情分布比較図の可視化

## 概要

推論 1「似ているはずのコード進行群に、異なる感情が混じるのはなぜなのか？何が紙一重なのか？」を検証するための可視化モジュールです。

## 機能

1. **クラスタリング**: コード進行の距離行列からクラスタリングを実行
2. **感情分布分析**: 各クラスタ内の感情分布を統計的に分析
3. **可視化**: 箱ひげ図、バイオリンプロットで感情分布を可視化
4. **レポート生成**: 分析結果を Markdown 形式でレポート生成

## 使い方

```bash
python run_cluster_emotion_analysis.py
```

## 出力ファイル

- `cluster_emotion_boxplot.png`: クラスタごとの感情分布の箱ひげ図
- `cluster_emotion_violinplot.png`: 上位 5 クラスタの感情分布のバイオリンプロット
- `cluster_emotion_statistics.csv`: クラスタごとの感情分布の統計表
- `cluster_emotion_analysis_report.md`: 分析結果のレポート

## 出力先

`vis_system/cluster_emotion_analysis/` ディレクトリに保存されます。

## クラスタリング手法

- `kmeans`: k-means クラスタリング（デフォルト、15 クラスタ）
- `dbscan`: DBSCAN クラスタリング
- `hierarchical`: 階層的クラスタリング

## 必要な依存関係

### 必須

- `numpy`: 数値計算
- `json`: JSON データの読み込み（標準ライブラリ）

### 推奨（可視化のため）

- `matplotlib`: 箱ひげ図、バイオリンプロットの生成
- `seaborn`: 可視化のスタイリング
- `sklearn`: k-means、DBSCAN、MDS によるクラスタリング
- `scipy`: 階層的クラスタリング

### オプション

- `pandas`: CSV 出力の最適化（pandas なしでも動作します）

## 注意事項

- 距離行列の計算には時間がかかる場合があります（数千点のデータで数分〜数十分）
- メモリ使用量が大きい場合があります（大規模データセットの場合）
- sklearn がインストールされていない場合、簡易クラスタリングが使用されます
- matplotlib がインストールされていない場合、可視化はスキップされ、レポートのみが生成されます
