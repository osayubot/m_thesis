# アーティストごとの典型パターン使用傾向の可視化分析方法

## 現在の可視化の特徴

- **点の色**: 各点の色は、そのコード進行が**最も近い典型コード進行**を示している
  - **青（#0000FF）**: odo（王道進行）に最も近い
  - **赤（#FF0000）**: komuro（小室進行）に最も近い
  - **緑（#00FF00）**: marusa（丸サ進行）に最も近い

## アーティストごとの典型パターン使用傾向を見る方法

### 1. **アーティストでフィルタリングして、色の分布を観察する**

**手順**:

1. アーティストフィルターで特定のアーティストを選択
2. 表示される点の色の分布を目視で確認

**解釈**:

- **青（odo）の点が多い** → そのアーティストは「王道進行に近いコード進行パターン」を多用している
- **赤（komuro）の点が多い** → そのアーティストは「小室進行に近いコード進行パターン」を多用している
- **緑（marusa）の点が多い** → そのアーティストは「丸サ進行に近いコード進行パターン」を多用している
- **3 色が混在している** → そのアーティストは様々な典型パターンを使い分けている（例：GreeeeN のような多様性）

### 2. **クラスタの形成パターンを観察する**

**手順**:

1. アーティストでフィルタリング
2. 同じ色の点が密集しているか、分散しているかを確認

**解釈**:

- **同じ色の点が密集している（明確なクラスタ形成）** → その典型パターンに**強く偏っている**、またはその典型パターンの**変形パターン**を多用している
- **色が混在して分散している** → 典型パターンへの依存度が低く、**多様なコード進行**を使用している
- **特定の色が大きな塊を形成** → その典型パターンを「お気に入り」として多用している可能性

### 3. **領域への集中度を観察する**

**手順**:

1. アーティストでフィルタリング
2. 点がどの領域に集中しているかを確認（左上、中央、右下など）
3. その領域の主な色を確認

**解釈**:

- **特定の領域に集中** → その領域に対応する典型パターンとの距離関係に偏りがある
- **全体に分散** → 典型パターンへの距離関係が多様

### 4. **複数のアーティストを比較する**

**手順**:

1. アーティスト A でフィルタリング → 色の分布を確認
2. アーティスト B でフィルタリング → 色の分布を確認
3. 両者を比較

**解釈**:

- **アーティスト A が青中心、アーティスト B が赤中心** → A は王道進行系、B は小室進行系を好む
- **両方とも 3 色混在** → どちらも多様だが、混在の仕方が異なる場合は「多様性の質」が異なる可能性
- **一方が明確なクラスタ、もう一方が分散** → 一方は特定パターンに偏り、もう一方は多様

## 具体的な分析例

### 例 1: 「アーティスト X は王道進行を多用している」

**観察**:

- アーティスト X でフィルタリング
- 表示される点の多くが**青（odo）**である
- 青の点が密集したクラスタを形成している

**解釈**:

- アーティスト X は、王道進行（IV → V → iii → vi）に近いコード進行パターンを多用している
- これは「感動的・切ない印象」の楽曲が多いことを示唆する可能性がある

### 例 2: 「アーティスト Y は様々なパターンを使い分けている」

**観察**:

- アーティスト Y でフィルタリング
- 青・赤・緑が混在している
- 明確なクラスタは見られない

**解釈**:

- アーティスト Y は、3 つの典型パターンに依存せず、多様なコード進行を使用している
- これは「柔軟な音楽表現」や「独自のスタイル」を示唆する可能性がある

### 例 3: 「アーティスト Z は小室進行と丸サ進行の中間を多用している」

**観察**:

- アーティスト Z でフィルタリング
- 赤（komuro）と緑（marusa）の点が多い
- 赤と緑が混在した領域に集中している

**解釈**:

- アーティスト Z は、小室進行と丸サ進行の**両方に近い、または中間的な**コード進行パターンを好む
- これは「力強さとおしゃれさの両立」のような音楽的特徴を示唆する可能性がある

## 数値的な確認方法（将来的な拡張案）

もしプログラムを変更する場合の参考として：

1. **色の割合を計算する**

   - アーティストでフィルタリング後、青/赤/緑の点の割合を計算して表示

2. **typical_chord_distance の統計を表示**

   - 各アーティストについて、odo/komuro/marusa への平均距離や最小距離を表示

3. **ヒストグラムの表示**
   - 各典型コード進行への距離の分布をヒストグラムで表示

ただし、現在の可視化でも**目視で十分に傾向を把握できる**ため、上記の観察方法で分析が可能です。

## まとめ

現在の可視化システムでは、**アーティストでフィルタリングし、点の色の分布とクラスタ形成パターンを観察する**ことで、以下のことがわかります：

1. **どの典型パターンを多用しているか**（色の分布）
2. **パターンへの依存度**（クラスタの明確さ）
3. **多様性の度合い**（色の混在度）
4. **複数アーティスト間の比較**（フィルターを切り替えて比較）

これらの観察から、アーティストごとのコード進行パターンの特徴や好みを定性的に分析できます。
