# scattergraph と scattergraph2 の設計の違い（発表用サマリー）

## 1. 基本的な設計思想

| 項目           | scattergraph                                           | scattergraph2                                          |
| -------------- | ------------------------------------------------------ | ------------------------------------------------------ |
| **分析の起点** | **コード進行**（基準進行）                             | **感情**                                               |
| **データ分類** | 基準進行（odo/komuro/marusa）× 手法                    | 感情（8 種類）× 手法                                   |
| **主要な質問** | 「このコード進行パターンにはどんな感情が含まれるか？」 | 「この感情にはどんなコード進行パターンが使われるか？」 |

## 2. 次元削減の入力データ

### scattergraph

- **入力**: 全コード進行フレーズ間の**直接的な距離行列**（N×N）
- 全てのコード進行間の音楽的レーベンシュタイン距離を計算
- 距離行列を直接 MDS/UMAP/t-SNE に入力

### scattergraph2

- **入力**: **3 次元ベクトル** `[odo距離, komuro距離, marusa距離]`
- 各コード進行フレーズを 3 つの典型コード進行への距離で表現
- この 3 次元ベクトルを 2 次元にマッピング

**意義**: scattergraph2 は、典型コード進行との関係性を**明示的に**可視化するアプローチ

## 3. 可視化の表現

### scattergraph

- **点の色**: 感情（主感情）に基づく色分け
- **点の形状**: 円グラフ（pie chart）で感情分布を表現
- **基準進行の表示**: 基準進行に近い点を特別な色の枠線で強調

### scattergraph2

- **点の色**: **典型コード進行への距離**に基づく色分け（青=odo, 赤=komuro, 緑=marusa）
- **点の形状**: シンプルな円形（パフォーマンス重視）
- **感情の表示**: ツールチップ内で感情分布を表示（ホバーで自動表示）

## 4. ファイル構成とデータ構造

### scattergraph

```
vis_system/scattergraph/data/
  ├── mds_odo_pie_data.json      （全コード進行を含む）
  ├── mds_komuro_pie_data.json   （全コード進行を含む）
  ├── mds_marusa_pie_data.json   （全コード進行を含む）
  └── [手法]_[基準進行]_pie_data.json
```

### scattergraph2

```
vis_system/scattergraph2/data/
  ├── JOY_umap.json              （JOYの感情を持つコード進行のみ）
  ├── JOY_tsne.json
  ├── SADNESS_umap.json          （SADNESSの感情を持つコード進行のみ）
  ├── SADNESS_tsne.json
  └── [感情]_[手法].json
```

## 5. 分析目的の違い

### scattergraph が適した分析

1. **基準進行の特徴分析**
   - 「王道進行に近いコード進行には、どのような感情が多く含まれるか？」
   - 基準進行を中心としたコード進行の空間的な分布を理解

### scattergraph2 が適した分析

1. **感情とコード進行の関係性分析**

   - 「JOY の感情を持つ歌詞には、どの典型コード進行パターンが多く使われるか？」
   - 「各感情において、コード進行パターンの多様性はどう異なるか？」

2. **クラスタ分析**
   - 同じ感情を持つコード進行が、典型コード進行との距離関係でどうクラスタリングされるか
   - 色が同じで近接している点のグループから、類似した距離関係を持つパターンを発見

## 6. 両システムの補完関係

両システムは**補完的**な関係にあり、異なる視点から同じデータを分析することで：

1. **双方向的な分析が可能**

   - scattergraph: コード進行 → 感情
   - scattergraph2: 感情 → コード進行

2. **包括的な洞察が得られる**

   - コード進行中心の分析と感情中心の分析を組み合わせることで、より深い理解が可能

3. **異なる研究目的に対応**
   - コード進行パターンの特徴を調べたい場合 → scattergraph
   - 感情表現とコード進行の関係を調べたい場合 → scattergraph2

## 7. 技術的な違いの要約

| 観点                 | scattergraph              | scattergraph2                                        |
| -------------------- | ------------------------- | ---------------------------------------------------- |
| データフィルタリング | コード進行と感情の有無    | 主感情が 0.5 以上（より厳密）                        |
| パフォーマンス       | 円グラフ描画で重い        | シンプルな円形で軽量                                 |
| データ量制限         | なし                      | max_items_per_emotion で制限可能                     |
| データの粒度         | コード進行ごとに 1 つの点 | コード進行フレーズごとに 1 つの点（1 フレーズ=1 点） |
