# scattergraph と scattergraph2 の設計の違い

## 概要

本研究では、コード進行と歌詞感情の関係性を可視化するために、2 つの異なるアプローチを実装しています。それぞれ異なる分析視点と研究目的を持っています。

---

## 1. 基本的な設計思想の違い

### scattergraph（第 1 版）

**設計思想**: **基準進行（典型コード進行）中心の可視化**

- **データのグルーピング**: 基準進行（odo/komuro/marusa）ごとにデータを分類
- **分析の視点**: 「王道進行に近いコード進行には、どのような感情が含まれるか？」
- **可視化の焦点**: 基準進行との距離関係によるコード進行の分布と、その各点における感情分布

### scattergraph2（第 2 版）

**設計思想**: **感情中心の可視化**

- **データのグルーピング**: 感情（JOY/SADNESS/ANGER など 8 感情）ごとにデータを分類
- **分析の視点**: 「JOY の感情を持つ歌詞には、どのようなコード進行パターンが使われるか？」
- **可視化の焦点**: 感情ごとのコード進行パターンの分布と、3 つの典型コード進行への距離関係

---

## 2. データ構造の違い

### scattergraph のデータ構造

**ファイル構成**: `[基準進行]_[手法].json` (例: `mds_odo_pie_data.json`)

```json
{
  "points": [
    {
      "x": 74.97,
      "y": 30.54,
      "r": 4,
      "pie": [
        {
          "label": "SADNESS",
          "c": "#5150F8",
          "v": 100.0,
          "lyrics": [...]
        }
      ],
      "progression": "vii - I - iv - I"
    }
  ]
}
```

**特徴**:

- 1 つの JSON ファイルに**全てのコード進行フレーズ**を含む（感情に関係なく）
- 各点の`pie`配列に、そのコード進行に関連する**全ての感情と歌詞**を格納
- 基準進行（odo/komuro/marusa）ごとに 3 つの JSON ファイルを生成

### scattergraph2 のデータ構造

**ファイル構成**: `[感情]_[手法].json` (例: `JOY_umap.json`)

```json
{
  "emotion": "JOY",
  "method": "UMAP",
  "points": [
    {
      "x": 63.83,
      "y": 9.55,
      "r": 6,
      "progression": "G",
      "pie": [
        {
          "label": "JOY",
          "v": 72.02,
          "c": "#FFFF73",
          "lyrics": [...]
        }
      ],
      "reference_color": "#0000FF",
      "reference_name": "odo",
      "typical_chord_distance": {
        "odo": 1.5,
        "komuro": 1.5,
        "marusa": 2.0
      }
    }
  ]
}
```

**特徴**:

- 1 つの JSON ファイルに**特定の感情（主感情）を持つコード進行フレーズのみ**を含む
- 感情ごとに 8 つの JSON ファイルを生成（8 感情 × 手法数）
- 各点に`reference_color`と`reference_name`を持ち、最も近い典型コード進行を色で表現
- `typical_chord_distance`により、3 つの典型コード進行への距離関係を明示

---

## 3. 次元削減の入力データの違い

### scattergraph

**入力**: コード進行間の**直接的な距離行列**

- 全てのコード進行フレーズ間の音楽的レーベンシュタイン距離を計算
- N×N の距離行列を作成（N = 全コード進行フレーズ数）
- この距離行列を直接 MDS/UMAP/t-SNE に入力

**利点**:

- コード進行間の直接的類似性を反映
- 基準進行は可視化後に特別な色の枠線で強調表示

### scattergraph2

**入力**: **3 次元ベクトル**（典型コード進行への距離）

- 各コード進行フレーズについて、3 つの典型コード進行（odo/komuro/marusa）への距離を計算
- 各点を`[odo距離, komuro距離, marusa距離]`の 3 次元ベクトルとして表現
- この 3 次元ベクトルを MDS/UMAP/t-SNE で 2 次元にマッピング

**利点**:

- 典型コード進行との関係性が明示的に可視化される
- 各点の色が最も近い典型コード進行を示すため、解釈が容易
- 3 次元から 2 次元への次元削減により、計算が効率的

---

## 4. 可視化の表現方法の違い

### scattergraph

- **点の色**: 感情（主感情）に基づく色分け
- **点の形状**: 円グラフ（pie chart）として各点を描画
- **基準進行の表示**: 基準進行に近い点を特別な色の枠線で強調表示
- **ツールチップ**: 円グラフのセグメントをクリックすると、その感情の歌詞を表示

### scattergraph2

- **点の色**: **典型コード進行への距離**に基づく色分け（青=odo, 赤=komuro, 緑=marusa）
- **点の形状**: シンプルな円形（パフォーマンス重視）
- **感情の表示**: ツールチップ内で感情分布を表示（クリック不要、ホバーで表示）
- **ツールチップ**: デフォルトで歌詞・アーティスト情報・感情分布を表示

---

## 5. 分析目的の違い

### scattergraph が適した分析

1. **基準進行の特徴分析**

   - 「王道進行に近いコード進行には、どのような感情が多く含まれるか？」
   - 「小室進行に近いコード進行と、丸サ進行に近いコード進行では、感情分布がどう異なるか？」

2. **コード進行パターンの発見**
   - 基準進行を中心とした、コード進行の空間的な分布を理解
   - 基準進行から離れた位置にあるコード進行パターンの発見

### scattergraph2 が適した分析

1. **感情とコード進行の関係性分析**

   - 「JOY の感情を持つ歌詞には、どの典型コード進行パターンが多く使われるか？」
   - 「SADNESS の感情では、コード進行の分布がどう異なるか？」

2. **感情ごとのコード進行パターンの特徴**

   - 各感情において、どの典型コード進行に近いコード進行が好まれるか
   - 感情によって、コード進行パターンの多様性がどう異なるか

3. **クラスタ分析**
   - 同じ感情を持つコード進行フレーズが、典型コード進行との距離関係でどうクラスタリングされるか
   - 色が同じで近接している点のグループから、類似した距離関係を持つコード進行パターンを発見

---

## 6. 研究上の意義の違い

### scattergraph の意義

- **コード進行中心の分析**: コード進行を起点として、そこに関連する感情を発見
- **基準進行の検証**: 提案した基準進行（odo/komuro/marusa）が実際のデータでどう機能するかを検証
- **コード進行の分類**: 基準進行を基準としたコード進行の空間的な分類

### scattergraph2 の意義

- **感情中心の分析**: 感情を起点として、そこに関連するコード進行パターンを発見
- **感情とコード進行の双方向的な関係**: 感情 → コード進行の関係を明示的に可視化
- **フィルタリングによる詳細分析**: 人気度・リリース年・アーティストなどでフィルタリングし、特定の条件での関係性を分析

---

## 7. 実装上の違い

### データフィルタリング

**scattergraph**:

- コード進行と感情の有無でフィルタリング（基本的なフィルタのみ）

**scattergraph2**:

- 主感情が 0.5 以上であることを必須条件として、感情ごとにデータを分類
- より厳密な感情ベースのフィルタリング

### パフォーマンス

**scattergraph**:

- 円グラフの描画により、大量のデータではレンダリングが重い

**scattergraph2**:

- シンプルな円形表示により、より多くのデータポイントを効率的に表示可能
- `max_items_per_emotion`パラメータにより、データ量を制限可能

---

## 8. まとめ：使い分けの指針

| 観点             | scattergraph                                           | scattergraph2                                          |
| ---------------- | ------------------------------------------------------ | ------------------------------------------------------ |
| **分析の起点**   | コード進行（基準進行）                                 | 感情                                                   |
| **主要な質問**   | 「このコード進行パターンにはどんな感情が含まれるか？」 | 「この感情にはどんなコード進行パターンが使われるか？」 |
| **可視化の焦点** | 基準進行との距離空間                                   | 感情ごとのコード進行分布                               |
| **色の意味**     | 感情（主感情）                                         | 典型コード進行への距離                                 |
| **データ分類**   | 基準進行（3 種類）                                     | 感情（8 種類）                                         |
| **適用場面**     | コード進行パターンの特徴分析                           | 感情とコード進行の関係性分析                           |

両システムは**補完的**な関係にあり、異なる視点から同じデータを分析することで、より包括的な洞察が得られます。
