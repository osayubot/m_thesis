## 総合的な解釈

### 観察結果

1. **同じクラスタ内でも感情のばらつきが大きい**
   - 多くのクラスタで、標準偏差が15%を超える感情が複数存在
   - これは、コード進行が似ていても、感情が必ずしも一致しないことを示唆

2. **「紙一重」の要因**
   - コード進行は感情の「器」であり、「決定要因」ではない
   - 作詞家、アーティスト、年代などの要因が感情に影響を与える可能性

3. **コード進行と感情の関係**
   - コード進行と感情の関係は、単純な相関ではなく、楽曲ごとの文脈や表現意図によって多様
   - 同じコード進行でも、異なる感情の歌詞が乗りうる
