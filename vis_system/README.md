# MDS 円グラフ可視化システム

音楽的レーベンシュタイン距離に基づく MDS（多次元尺度構成法）を用いて、コード進行を 2 次元空間に配置し、各点を円グラフで感情分布を可視化するシステムです。

## 機能

- **音楽的距離計算**: 和声機能・時系列的な流れ・循環性を考慮したレーベンシュタイン距離
- **MDS 可視化**: 高次元の距離行列を 2 次元に投影
- **感情分析**: 歌詞の感情を Plutchik の 8 感情に分類して円グラフで表示
- **インタラクティブ**: ホバー・クリックで詳細情報を表示

## 使い方

1. **ホバー**: 円グラフの上にマウスを置くと、tooltip が表示されます

   - 座標と歌詞数が表示されます
   - 各感情の割合が色分けされて表示されます

2. **クリック**: 円グラフの扇形をクリックすると、その感情の歌詞が表示されます

   - クリックした感情がハイライト表示されます
   - その感情に分類された歌詞のリストが表示されます

3. **円のサイズ**: 歌詞数に応じて円のサイズが変わります（歌詞が多いほど大きい）
   - 最小半径: 4px（歌詞数 1 件）
   - 最大半径: 20px（歌詞数 100 件以上）
   - 対数スケールで計算されます

## データ構造

生成される JSON ファイル（`mds_pie_data.json`）の構造:

```json
{
  "points": [
    {
      "x": 35.0,
      "y": 52.7,
      "r": 7.82,
      "lyricCount": 3,
      "songCount": 2,
      "pie": [
        {
          "label": "JOY",
          "c": "#FFD700",
          "v": 33.33,
          "lyrics": ["歌詞1", "歌詞2", ...]
        },
        ...
      ]
    },
    ...
  ],
  "emotionSongs": {
    "JOY": [...],
    "SADNESS": [...],
    ...
  }
}
```

## トラブルシューティング

- **JSON が読み込めない場合**: ローカルサーバーを使用してください
- **円のサイズが変わらない場合**:
  - ブラウザのキャッシュをクリアしてください
  - JSON ファイルの`r`フィールドが正しく生成されているか確認してください
- **歌詞が表示されない場合**:
  - JSON に`lyrics`フィールドが含まれているか確認してください
  - クリック座標が正しく取得されているかブラウザのコンソールで確認してください
- **歌詞数 0 のポイントが表示される場合**:
  - データ生成時に歌詞がないセクションが含まれていないか確認してください
  - `run_visualize_data.py`を再実行して JSON を再生成してください
